On drawn versus faded

Drawn, every time. 5c Mug wrap — seal, ink body

The straight lockup — your actual title-purple.svg, recoloured to cream, not type — split by the handle so only one element faces the viewer at a time: emblem to a colleague across the desk, wordmark to you. Ink body (#2C2530) rather than plum: a plum mug fights whatever is in it, and ink is the new ramp step earning its keep. The seal is your shipped logo-on-white-circle.svg, not a CSS disc — which settles your berth question with a number: measured, the blades occupy 91% of the disc width and 94% of its height, so roughly 4.5% of the diameter is clear white on each side. That spacing is baked into the asset and it is well judged; preserve it rather than adding to it. One print note only: the circle is drawn at r="50%" inside a 1092×1111 box, which SVG resolves against the diagonal, so the disc overruns the artboard by about 5 units and gets a flat shave at left and right. Give the print file a slightly wider canvas than the raw viewBox so the seal stays perfectly round. This is the safe draft; 5a is the one people photograph.

Print notes

Wrap area for an 11 oz mug is roughly 8.5 × 3.5 in — set up at 2550 × 1050 px, 300 dpi, and keep everything 0.25 in clear of every edge. The dashed rule marks the handle. Vector only, no shadows, and check the ramp on a proof: dye-sublimation pushes plum toward blue, so #48177D is the one to watch.

On slogans

Leave them off. A slogan on merch dates faster than anything else you print, and yours would have to compete with a mark that already says the thing. If one is required later, it belongs on the base or inside the rim — found, not announced.

Still saturated, still gradient, still the most colourful thing on screen — so it still looks like the thing to press. And the label at .6 drops under contrast minimums, so the one part a user needs to read is the part that got weakest.

Proposed — flat, dropped out of the family
Continue

A neutral plum-tinted grey with full-strength text. It recedes because it left the brand family, not because it faded — and the label stays legible at 4.5:1. Losing the gradient is itself the signal, now that gradient means active premium.

Better still — say why
Continue
Pick a language first

A disabled button with no explanation is a dead end — the user can see the exit and not the lock. One line naming the unmet condition converts a blocked state into an instruction, and it costs nothing.

On cursor: not-allowed

Keep it — it is the honest cursor, and it is the only affordance blind to colour. But pair it with pointer-events: auto on a wrapper so the button can still receive hover and show a tooltip; a genuinely inert element cannot explain itself.

Never opacity is not wrong in general — Material 3 prescribes exactly this, 38% on content and 12% on container, and WCAG exempts inactive controls from contrast minimums, so Google is within the rules. But note separately: Material fades the label and the fill as two tokens and removes elevation outright. Fading the composited element is the part that fails, because the shadow and border go with it and the button dissolves into the panel — and 38% of a gradient stays the most saturated thing on the screen. Set the disabled colours directly, or you inherit the failure without the discipline.

.btn-primary:disabled {
  background: #e8e2e6;
  color: #8b8290;
  box-shadow: none;
  cursor: not-allowed;
  opacity: 1;
}
