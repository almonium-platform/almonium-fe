The Almonium Lexicon, by API

A learner’s dictionary for European languages, served as JSON. Every entry in every language has the same shape, Schema 4. The entries are written by our own pipeline of language models and checks, not copied from Wiktionary or any other dictionary. Open sources are used only to choose which words get an entry and to check facts such as gender, stress and pronunciation. The licence is a plain commercial one.

One schema, every language

A Spanish verb, a German noun and a Russian pronoun come back in the same structure, so one parser covers them all.

Lexemes and senses
Grammar, forms and pronunciation sit on the lexeme. Each sense has a stable id and a CEFR level.
Regions and labels
BCP 47 and UN M.49 codes say where a sense is used, only or mainly. Formality, attitude, time and normativity are separate fields.
Patterns and collocations
Each pattern is given as written and as parts: head, fixed words, open slots with case, form or mood.
Sounds
IPA for each variety, with weak forms and the context each one is said in.
